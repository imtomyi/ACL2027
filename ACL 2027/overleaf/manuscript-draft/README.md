# ACL 2027 manuscript draft

## Main files

- `warrant_route_acl2027_draft.md` — pre-data manuscript draft for **Who Should Be in the Loop? Allocating Expert Review for Qualitative Coding with Language Models**.
- `references.bib` — citation metadata with explicit archival/preprint status notes as of the review cutoff.

## What this draft is

This is a paper-shaped prospective draft: it contains the literature position, contribution boundary, research questions, controlled study design, routing baselines, analysis plan, ethics, limitations, and a results-reporting shell. It does not invent results or a final participant count.

The core positioning is:

> Prior work shows that people can revise, rate, and steer LLM qualitative-analysis systems. This paper tests which failures require which kind of expertise, and whether observable first-stage signals can allocate scarce expert review without hiding unsupported, less-frequent, or negative-case evidence.
