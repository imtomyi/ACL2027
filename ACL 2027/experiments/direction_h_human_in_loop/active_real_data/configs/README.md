# Real-data configuration area

This directory is reserved for future, text-free Direction H configuration
records for real Dreaddit and real `agyw_focus_groups`. It must not contain
source records, excerpts, participant narratives, raw identifiers, or copied
dataset rows.

No configuration is active. A configuration may be created only after the
applicable documentary gates are complete, and it must bind the exact corpus
receipt, split, allowed fields, study manifest, model endpoint, reviewer role,
retention plan, and release class without weakening the existing fail-closed
controls.

## Prepared internal draft

[`internal_controls.draft.json`](internal_controls.draft.json) records proposed
internal defaults that can be prepared without corpus access: role separation,
data minimization, Charlie's developer-researcher case status, blinded review,
frozen revision, retention/deletion procedure, incident response, and
default-deny release. It deliberately leaves owners, reviewers, dates,
endpoint profiles, privacy decisions, sampling counts, hashes, and release
classes pending.

The draft is not an active configuration, does not complete a governance gate,
and cannot be copied into the local governance record as evidence of external
approval.
