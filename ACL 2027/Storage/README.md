# Storage

This folder contains completed or generated artifacts retained for provenance
but not used as active source inputs.

- `rq2_personal_local_diagnostic/` contains active private exploratory records
  produced from the pinned real-corpus working copies with a loopback-only
  local model. Source-bearing files remain permission-restricted and are not
  publication, submission, or redistribution artifacts.

- [`synthetic-results/`](synthetic-results/README.md) contains all generated
  results produced from fictional or demo datasets, the archived source package
  for the removed qualification, and prior manuscript builds retained for audit.
- [`manuscript-exports/`](manuscript-exports/) contains superseded manuscript
  PDFs and upload bundles retained only for provenance.

Nothing under `Storage/` is automatically an active manuscript input. Test-only dataset
fixtures may remain under `dataset/`, but experiments and results derived from
them are never manuscript-eligible.
