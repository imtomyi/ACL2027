# Synthetic results storage

Everything below this directory is generated from fictional data. Nothing here
is a result for the real AGYW, Dreaddit, KODIS, or CANDOR corpora.

| Folder | Contents |
|---|---|
| `dataset-demos/kodis_demo/` | Validated KODIS preprocessing demonstration |
| `dataset-demos/candor_demo_output/` | Validated CANDOR preprocessing demonstration |
| `model-qualification/20260825_synthetic_qualification/` | Completed qualitative-coding model qualification, blinded judgments, summaries, workbook, and previews |
| `archived-experiments/direction-j/20260825_synthetic_paired_qualification_prepared/` | Archived fictional paired-rating package |
| `manuscript-removals/20260826/` | Pre-removal manuscript source snapshots and superseded builds that contained the qualification |

These locations are canonical records. The removed qualification's source
package and generated manuscript table are archived under
`model-qualification/20260825_synthetic_qualification/source-package/`.
Source-like unit-test fixtures remain under `dataset/fixtures/`.

No file in this tree may be included in a manuscript, copied into an active
manuscript results section, used for manuscript model selection, or used to
replace a missing-result placeholder.
