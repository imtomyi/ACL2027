# Literature library

This folder contains literature only. Use it for reading and source-paper lookup.

| Folder | Contents |
|---|---|
| `01_original-seed-papers` | The original supplied papers. |
| `02_must-read-papers` | Curated high-priority reading set. |
| `03_low-priority-papers` | Relevant but lower-priority reading. |
| `04_recent-publications-by-venue` | Recent work separated by peer-review and venue class. |
| `05_recent-publications-chronological` | The same recent literature organized by year, plus the full metadata timeline. |
| `paper_organization_manifest.csv` | Source, destination, and hash ledger for the reading folders. |

The manuscript lives in `../overleaf/`. Screening records, scripts, generated review deliverables, and working files live in `../review/`.
