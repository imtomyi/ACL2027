# Literature review workspace

This folder contains the reproducible review workflow and its generated artifacts.

| Folder | Contents |
|---|---|
| `01_research-evidence` | Screening records, extraction files, scripts, evidence data, and source full text. |
| `02_review-deliverables` | Generated report, workbook, PDF, DOCX, previews, and audit outputs. |
| `03_working-files` | Temporary downloads and working PDFs used during the review. |

The numbered entries point into `_workspace/`, which preserves the sibling paths expected by the existing scripts and audit records. The literature collections themselves live in `../paper/`; internal compatibility links let the reproducible workflow continue to use its recorded paths. Use the numbered folders for normal browsing and leave `_workspace/` intact.
