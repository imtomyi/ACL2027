[calc-00001] helpful=1 harmful=0 :: Current Ratio = Current Assets / Current Liabilities. Always format the result as a floating point number, rounding to two decimal places if required.
[calc-00002] helpful=0 harmful=0 :: Return on Investment (ROI) = Net Profit / Total Investment. Always format the result as a floating-point decimal (e.g., 0.2) without percentage symbols or ×100 conversion.
